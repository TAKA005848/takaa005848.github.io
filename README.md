# 喫煙難民マップ — GitHub Pages版

現在の公開版をそのまま書き出した静的サイトです。ビルド・外部バックエンド・APIキーは不要です。

## 公開手順

1. GitHubの takaa005848 アカウントに、takaa005848.github.io という名前の公開リポジトリを用意します。
2. このZIPを解凍し、中身をリポジトリ直下へアップロードします。index.html が直下にある状態にしてください。ZIPそのものをアップロードするのではありません。
3. Settings → Pages で Deploy from a branch を選び、main ブランチの / (root) を指定して保存します。
4. 公開完了後、https://takaa005848.github.io/ で利用できます。

.nojekyll は静的ファイルをそのまま配信するための空ファイルです。隠しファイルも含めて配置してください。

## 含まれるもの

- index.html / style.css / app.js：現在の画面と機能
- assets/kitsuen-header.png：現在のヘッダー画像
- spots.json：現在公開しているProduction店舗80件（渋谷区37・新宿区32・港区11）
- spots-unresolved.json：現在の座標未解決14件の保管用データ。サイトには表示されません。
- wards.geojson：行政区境界
- vendor/：Leafletとライセンス

店舗データ、ピン、区切り替え、フィルター、詳細カード、赤い区境界、区外の白マスク、現在地機能は元の公開版から変更していません。すべてのアプリ内ファイル参照は相対パスです。

## 動作について

地図の背景は従来どおりOpenStreetMapの地図タイルを取得するため、インターネット接続が必要です。独自のサーバーやバックエンドは不要です。
現在地機能はHTTPS上で、利用者がブラウザの位置情報を許可すると動作します。
index.htmlの直接ダブルクリックではJSONの読み込みが制限されることがあるため、GitHub PagesまたはローカルHTTPサーバーで確認してください。
